# 🐍 Lista de Revisão — Programação em Python

Projeto desenvolvido como parte da lista de revisão de Programação em Python do **Instituto Federal de Santa Catarina (IFSC)**.

O objetivo é revisar e praticar os principais conceitos da linguagem Python por meio de 10 exercícios progressivos, simulando situações do cotidiano e desenvolvendo programas completos.

## 🎯 Objetivos do projeto

Praticar os seguintes conteúdos:

- **Laços de repetição:** `for` e `while`.
- **Estruturas condicionais:** `if`, `elif` e `else`.
- **Listas e dicionários:** armazenamento e manipulação de informações.
- **Funções:** parâmetros, argumentos, valores padrão e `return`.
- **Módulos:** divisão do código em diferentes arquivos e utilização de `import`.
- **JSON:** leitura, escrita e persistência de dados em arquivos.
- **SQLite:** criação de tabelas, consultas SQL e manipulação de bancos de dados.
- **Tratamento de erros:** validação de entradas e utilização de `try` e `except`.

## 📌 Regras gerais de desenvolvimento

Todos os exercícios devem respeitar os requisitos estabelecidos no enunciado original.

Algumas regras importantes:

1. Validar as informações digitadas pelo usuário.
2. Não permitir que entradas inválidas encerrem inesperadamente o programa.
3. Exibir mensagens de erro quando necessário e solicitar novamente a informação.
4. Utilizar funções e módulos conforme solicitado em cada questão.
5. Utilizar os comandos SQL com parâmetros (`?`) nas operações com SQLite.
6. Manter a organização dos arquivos de acordo com cada exercício.
